2″ (50 mm) Main Drain Flow Analysis

Water-supply estimation per AXA XL Property Risk Consulting Guideline PRC.14.1.2.2

Engineer’s Caution — Read Before Use

  • This is not a hydrant flow test. A hydrant or other large-volume flow test remains the preferred method for water-supply evaluation. A 2″ drain test is an interim procedure when a proper flow test is not possible.
  • Results are typically more conservative than a hydrant test because of unknown friction loss through alarm and check valves at low flows (valves may only partially open and “flutter” or “chatter”).
  • Use only for Light Hazard or Ordinary Hazard occupancies. Do not rely on a 2″ drain test for Extra Hazard or storage occupancies where larger flows are required.
  • The result applies only at the test point. It cannot be extrapolated to larger flows, other risers, or other areas of the facility.
  • Best accuracy (±5%) is achieved when the flow developed in the test is close to the system’s actual demand.

4. Test Scenarios

Each scenario is one flow reading and produces one point on the supply curve. Mark which drains are flowing simultaneously, enter the residual pressure at each flowing drain’s riser gauge, and select which gauge is the reference point for the supply curve.

5. Results

Calculations use a discharge coefficient c = 0.85 (the more conservative value, applicable to a 45° elbow discharge or an unreamed 2″ outlet) and Hazen-Williams friction loss with C = 120 for the 2″ drain pipe (Schedule 40, ID ≈ 2.067″). The supply curve is fit and plotted on N1.85 semi-exponential graph paper.

This tool implements the method described in AXA XL PRC.14.1.2.2 (2020). It is an aid only; the responsible engineer must interpret results and confirm applicability.
